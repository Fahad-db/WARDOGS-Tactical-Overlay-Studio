## 🧭 What This Suite Offers

### 🖥️  Operator Status Panel
A persistent, customizable card view displaying:
- Current unit vitals and condition indicators
- Active equipment loadout summaries
- Historical activity log with timestamps
- Integrated communication status (Team / Squad / Platoon)

### 🗺️  Sector Control Module
A dedicated overhead perspective of the operational area, featuring:
- Real-time zone ownership visualization (color-coded)
- Claim progression bars with percentage breakdown
- Landmark markers for strategic points
- Optional grid overlay for coordinate-based communication

### 🚁  Vehicle & Support Tracker
Monitor all deployable assets without leaving the main screen:
- Vehicle health, fuel, and position data
- Support cooldown timers (artillery, airstrikes, supply drops)
- Quick-select assignment for prioritized targets
- Last-seen timestamp for each asset

### 🧰  Tactical Utility Drawer
A collapsible side panel packed with mission-critical helpers:
- Distance calculator between any two map points
- Compass bearing indicator
- On-screen notepad for intel sharing
- Route planning tool with waypoint markers

### ⌨️  Rapid-Input Action Mapper
Customize your keyboard or mouse workflow with:
- Per-action keybinding (up to 24 unique assignments)
- Multi-action macros with user-defined delay intervals
- Toggleable hold-to-activate or press-once modes
- Profile-specific binding sets that auto-switch by context

### 👤  Operator Profile Manager
Save, load, and share your entire configuration:
- Separate profiles for different mission types (Recon, Assault, Support)
- Export/import settings as portable text files
- Automatic profile backup with rollback option
- Cloud-sync readiness for multi-device users
